## Description

Seasonal Letters adds configurable decorative stationery to LaTeX documents.
It separates letter content from page decoration and combines four seasonal
palettes and original vector botanical motifs with seven weekday emblems.
The package supports different first-page and continuation-page layouts,
plain, ruled and grid backgrounds, named themes, and user-supplied artwork.
A print mode uses white paper and grey built-in decoration while omitting
background images and ruling. An optional class provides an informal
personal-letter layout. No external image collection, proprietary fonts, or
shell escape is required for the built-in designs.

## Announcement

Seasonal Letters is a new LaTeX package for decorative personal correspondence.
It provides four seasonal designs, seven independent weekday emblems, natural
multi-page letter flow, quieter continuation pages, and an ink-saving print
mode. Named themes and artwork hooks let users extend the stationery without
editing the package source. The release includes a manual, a seven-design
gallery, and examples using both the supplied class and the standard letter
class. All built-in motifs are original vector drawings.
