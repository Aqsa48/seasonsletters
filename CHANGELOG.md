# Changelog

## 0.1.0 - 2026-11-05

- Initial implementation of seasonal palettes and seven weekday emblems.
- First-page and continuation-page stationery; per-letter page counting.
- Plain, ruled, and grid backgrounds with adjustable guide rectangle.
- White-paper print mode and configurable border.
- Named themes and hooks for user-supplied artwork.
- Optional personal-letter class, examples, manual, and build checks.
