# Uploading Seasonal Letters to CTAN

This guide is for version 0.1.0. No CTAN upload has been submitted by the assistant.

1. Open https://ctan.org/upload.
2. Enter the package details below.
3. Copy the Description, Announcement and Administrative notes from
   CTAN-SUBMISSION.md into the matching fields.
4. Select the MIT/Expat licence entry.
5. Attach dist/seasonalletters-0.1.0-ctan.zip as the archive.
   Use this clean archive, not GitHub's automatically generated source ZIP.
6. Use https://github.com/Aqsa48/seasonsletters as both Repository and Home page;
   use https://github.com/Aqsa48/seasonsletters/issues for Bug tracker. Leave other optional links blank if
   there is no corresponding service.
7. Review the next screen and follow the form's final submission steps.
8. Keep CTAN's confirmation and watch aqsa.umar3505@gmail.com for questions
   from the CTAN team. Address any requested changes; submission is not a
   guarantee of acceptance.

Before submitting, review the manual and gallery. Run the GitHub engine checks
and resolve any failures before distributing a release. The local release was
tested with Tectonic's XeTeX backend; the configured CI checks also cover native
pdfLaTeX, XeLaTeX and LuaLaTeX.

The package archive contains handwritten runtime sources, a README and licence,
PDF documentation with its LaTeX source, examples, and a file manifest. It has no
build logs, auxiliary files, compiler binaries, or private credentials.
